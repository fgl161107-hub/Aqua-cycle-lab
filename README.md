# SAGE-AI Website

Website prototype siap GitHub Pages.

## Cara menjalankan
1. Upload seluruh isi folder ini ke repository GitHub.
2. Pastikan `index.html` berada di root repository.
3. Buka **Settings → Pages**.
4. Pilih **Deploy from a branch**, branch `main`, folder `/ (root)`.
5. Simpan dan tunggu GitHub Pages menerbitkan situs.

Tidak membutuhkan backend atau API.
