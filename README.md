# SAGE-AI — FINAL GABUNGAN

Satu website SAGE-AI berisi dua materi aktif:
- Siklus Air
- Ekosistem

Keduanya mempunyai jalur 7 tahap yang linear: Eksplorasi → Klasifikasi/Observasi → Hubungkan → Eksperimen/Simulasi → Analisis → Tantangan → Refleksi.

## Interaksi
- Foto lingkungan nyata menjadi dasar eksplorasi dan eksperimen.
- Hotspot dapat diketuk.
- Klasifikasi dapat dikoreksi jika salah.
- Urutan dapat diulang jika salah.
- Slider mengubah hasil simulasi/eksperimen.
- Jawaban analisis dan tantangan dapat dicoba lagi.
- Tahap berikutnya terkunci sampai tahap sebelumnya selesai.
- Progress disimpan di localStorage browser.

## Upload GitHub Pages
Upload seluruh isi folder ini ke repository GitHub, lalu aktifkan GitHub Pages dari branch yang dipakai.

Catatan: visual foto membutuhkan koneksi internet karena gambar dimuat dari Wikimedia Commons. Jika ingin versi sepenuhnya offline, foto dapat dibundel ke folder `assets/` dengan tetap mempertahankan atribusi lisensinya.
