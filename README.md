# SAGE-AI — Revisi Full

Versi ini mempertahankan alur investigasi SAGE-AI tetapi memperbaiki pengalaman mobile:
- setiap tahap dirancang dalam satu viewport HP tanpa scroll vertikal;
- objek Explore bisa disentuh dan digeser;
- navigasi mengikuti satu jalur, tahap berikutnya terkunci sampai tahap sebelumnya selesai;
- tahap yang sudah selesai tetap bisa dibuka kembali untuk revisi;
- susunan siklus air bisa dihapus dari belakang atau diulang total jika salah;
- progress dan badge tersimpan di localStorage.

## Deploy ke GitHub Pages
Upload seluruh file di repository dan pastikan `index.html` berada di root folder yang dipublish.

Jika sebelumnya pernah membuka SAGE-AI versi lama di perangkat yang sama, gunakan tombol `↻` untuk memulai ulang progress versi ini.
