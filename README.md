# SAGE-AI
## Smart Adaptive Guide for Environmental Learning

**Interactive Science Learning Media — Grade 5 Elementary School**

Prototype topic: **Water Cycle / Siklus Air**

SAGE-AI is an interactive digital science laboratory. Students explore a water environment, make predictions, run simulations, analyze evidence, explain findings, and reflect on their learning.

### Core journey
Explore → Observe → Predict → Experiment → Analyze → Explain → Reflect

### GitHub Pages
The project must run as a static web application and must be deployable through GitHub Pages without a backend.

See `PROMPT.md` for the complete coding/build specification.
